# DesaPortal-ID 🌾

> Template website resmi Desa yang modern, ramah, dan menonjolkan transparansi serta potensi lokal.

DesaPortal-ID adalah inisiatif *open-source* untuk membantu desa-desa di Indonesia memiliki kehadiran digital yang profesional tanpa biaya mahal. Template ini dirancang khusus untuk memenuhi kebutuhan administrasi desa, transparansi dana, dan promosi UMKM lokal.

## ✨ Fitur Utama
- **Desain Ramah & Natural**: Skema warna bernuansa alam (Hijau & Terakota) yang hangat dan merakyat.
- **Transparansi APBDes**: Komponen khusus untuk menampilkan ringkasan keuangan desa secara visual.
- **Etalase Potensi Desa**: Halaman khusus untuk mempromosikan pariwisata dan UMKM warga.
- **Layanan Administrasi**: Kerangka UI untuk pengajuan surat keterangan pengantar RT/RW dan desa.
- **Performa Ringan**: Dioptimalkan untuk koneksi internet terbatas di wilayah pedesaan (dibangun dengan Vite + React).

## 🚀 Teknologi yang Digunakan
- **Framework**: React 18
- **Build Tool**: Vite
- **Styling**: Vanilla CSS (CSS Modules)
- **Ikon**: Lucide React

## 📦 Cara Memulai (Instalasi)

Ikuti langkah-langkah berikut untuk menjalankan proyek ini:

1. **Clone repository ini**
   ```bash
   git clone https://github.com/itsasakdotid/DesaPortal-ID.git
   ```

2. **Masuk ke direktori proyek**
   ```bash
   cd DesaPortal-ID
   ```

3. **Install dependensi**
   ```bash
   npm install
   ```

4. **Jalankan server pengembangan**
   ```bash
   npm run dev
   ```

5. **Buka di Browser**
   Kunjungi `http://localhost:5173` untuk melihat hasilnya.
